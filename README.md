# 🐍 OOP in Python — Abstraction & Encapsulation

> **hiding the details** · part of a hands-on **Python Object-Oriented Programming** learning series.

## Concept

Demonstrates **abstraction** (exposing only essential features) and **encapsulation** (bundling data + behaviour into one unit) with a `Car` that hides its clutch/accelerator internals behind `start()`.

## Run it

```bash
python Oop4.py
```

## The series

This repo is one lesson in a step-by-step OOP journey — from classes & objects through constructors, encapsulation, inheritance, `super()`, and decorators like `@classmethod` and `@property`. Browse the other `Oop*` repos on my profile to follow the full path.
